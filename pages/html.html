SEGUNDO PASO

LA ESTRUCTURA DE UNA PÁGINA HTML

Una página web no es un conjunto de etiquetas colocadas al azar. Existe una estructura que permite al navegador interpretar el documento.

🧠
IDEA CENTRAL

Pensá en HTML como un edificio.

Hay una estructura general, habitaciones dentro de ella y contenido dentro de esas habitaciones. HTML funciona de una manera similar.

EXPLORÁ LA ESTRUCTURA

Hacé clic en cada parte.

Descubrí qué función cumple cada elemento del documento.

CÓDIGO —

01 · DOCTYPE

¿Qué es ``?

Le indica al navegador que el documento utiliza el estándar moderno de HTML.

<!DOCTYPE html>

No es una etiqueta HTML común.

Es una declaración que aparece al comienzo del documento para indicar el tipo de documento.

02 · HTML

El contenedor principal

El elemento <html> envuelve todo el documento HTML.

<html>
DOCUMENTO

Inicio

Marca el comienzo del elemento raíz del documento.

<head>
INFORMACIÓN

Datos de la página

Contiene información y recursos utilizados por el documento.

<body>
CONTENIDO

Lo que vemos

Contiene el contenido que forma la interfaz visible de la página.

03 · HEAD VS BODY

¿Cuál es la diferencia?

⚙️

HEAD

Contiene información sobre el documento que normalmente no aparece como contenido principal de la página.

<title> <meta> <link>
👁️

BODY

Contiene el contenido y los elementos que forman la experiencia visible del sitio.

<h1> <p> <button>

TODO JUNTO

La estructura básica completa

Esta estructura será la base de muchísimas páginas que construiremos más adelante.

HTML 
<!DOCTYPE html>
<html>

    <head>

        <title>Mi página</title>

    </head>


    <body>

        <h1>Hola Mundo</h1>

    </body>

</html>
⚠️
ERROR COMÚN

No mezcles HEAD y BODY.

Aunque el navegador puede ser tolerante con ciertos errores, mantener una estructura correcta hace que el documento sea más fácil de entender y mantener.
