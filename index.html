TERCER PASO

ETIQUETAS, ELEMENTOS Y ATRIBUTOS

Para leer y escribir HTML con confianza necesitamos saber exactamente qué representa cada parte del código.

🧠
IDEA CENTRAL

No todo lo que ves entre < > es un elemento completo.

Una etiqueta es una parte del código. Un elemento puede incluir etiqueta de apertura, contenido y etiqueta de cierre. Un atributo agrega información adicional.

🏷️ 01

Etiqueta

Es la marca utilizada para identificar un elemento HTML.

<p>
🧱 02

Elemento

Es la combinación del conjunto que forma una pieza de HTML.

<p>Hola</p>
⚙️ 03

Atributo

Agrega información adicional o configuración al elemento.

href="index.html"

PARTE ANALIZADA —

01 · ETIQUETA DE APERTURA

¿Dónde empieza el elemento?

La etiqueta de apertura marca el comienzo de un elemento.

<h1>

La etiqueta de apertura

En este ejemplo, <h1> indica que comienza un encabezado de nivel 1.

02 · CONTENIDO

Lo que hay dentro

Entre las etiquetas puede existir contenido que el navegador mostrará o utilizará.

Hola Mundo

El contenido

En este caso, el texto Hola Mundo es el contenido del elemento.

03 · ETIQUETA DE CIERRE

¿Dónde termina?

Muchos elementos tienen una etiqueta de cierre que indica dónde finaliza el contenido.

</h1>

La etiqueta de cierre

La barra / permite diferenciar la etiqueta de cierre.

04 · ATRIBUTOS

Agregando información adicional

Los atributos aparecen dentro de la etiqueta de apertura.

<a href = "index.html" > Inicio </a>
href Nombre del atributo
= Asigna el valor
"index.html" Valor del atributo

05 · ANIDAMIENTO

Los elementos pueden contener otros elementos.

HTML se organiza como una estructura de elementos dentro de otros elementos.

01 <div>
02 <h1> Hola </h1>
03 <p> Texto </p>
04 </div>

Hola

Texto

⚠️
ERROR COMÚN

No olvides diferenciar etiqueta y elemento.

<p> es una etiqueta de apertura. <p>Hola</p> representa el elemento completo.
